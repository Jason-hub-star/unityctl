## 6. unityctl 출품 강점 / 보완점

**강점**
- AI 에이전트 ↔ Unity 에디터 연동이라는 **시의성 높은 주제**(MCP·LLM 트렌드 정면 부합).
- 887 자동화 테스트 + 3-OS CI 매트릭스 + 모듈형 아키텍처 → 평가의 "완성도·DevOps" 항목 강함.
- CLI + MCP 하이브리드, 토큰 최적화, 결정적 IPC 등 독자적 설계 포인트 다수.

**보완점**

- README의 "설치→첫 사용" 온보딩을 외부인 기준으로 점검.

## 6.5 경쟁 분석 — Unity AI 및 MCP 도구 대비 차별점

> 핵심 메시지: **Unity AI는 "에디터 안에서 사람이 대화로 쓰는" 보조 도구 + 구독/벤더 종속.
> unityctl은 "외부 AI 에이전트가 헤드리스로 에디터를 제어"하는 벤더 비종속 오픈소스.**

### Unity AI (Unity 6, 2026 공개 베타)
- 구성: **AI Assistant**(에디터 내 대화형 Ask/Plan/Agent) + **Generators**(텍스처·사운드·머티리얼 등 에셋 생성) + **Inference Engine**(구 Sentis, 런타임 추론).
- 과금: Personal 14일 무료 후 **유료 크레딧 구독**. Gemini 등 파트너 LLM에 종속.
- 한계: **에디터 UI 패널 전용** — 외부 프로그램/CI에서의 헤드리스 자동화 불가, 결정적 상태 제어·멀티 에디터·폐루프 검증 약함.

### 비교표
| 항목 | Unity AI | Unity MCP(공식/커뮤니티) | unityctl |
|------|----------|--------------------------|----------|
| 사용 환경 | 에디터 UI 패널 | IDE 에이전트 | **CLI + IDE MCP 병행** |
| 헤드리스(-batchmode) | ❌ | ❌(에디터 필수) | **✅** |
| 멀티 에디터 라우팅 | ❌ | ❌(보통 1연결) | **✅ editor select** |
| 벤더 종속 | 구독·파트너 LLM | 일부 구독 결합 | **무료·MIT, LLM 자유** |
| 시각 검증 폐루프 | ❌ | 제한적 | **✅ workflow verify/screenshot** |
| CI/CD 친화 | ❌ | 낮음 | **✅ GitHub Actions** |
| 테스트 커버리지 | 미공개 | 미공개 | **887개 / 3 OS** |

### 강조할 차별점 5
1. **외부 AI 에이전트가 헤드리스로 결정적 제어** — bash·CI·MCP 어디서든. (Unity AI는 에디터 대화 전용)
2. **벤더 비종속 오픈소스(MIT)** — 어떤 LLM·IDE와도 조합. (Unity AI는 구독·파트너 종속)
3. **CLI 단독 + MCP 분리** — IPC probe-first → batchmode 자동 폴백.
4. **시각 검증 폐루프** — screenshot·workflow verify로 에이전트가 결과를 스스로 확인.
5. **멀티 에디터 라우팅 + 887 테스트·3 OS CI** — 실무·평가의 "완성도·DevOps" 강점.

> ⚠️ 사실검증 주의: "토큰 96% 절감" 등 미검증 수치는 보고서/카피에 단정 표기 금지. CLAUDE.md 근거가 있는 "33→12 MCP 도구", "887 테스트"만 사용.

unityctl - AI 에이전트를 위한 Unity 에디터 제어 도구

**개발 목적** [200/200]
```
Unity는 2026년 'Unity AI'를 에디터에 내장했지만, 사람이 에디터 안에서 대화로 쓰는 보조 기능이고 특정 구독에 묶여 있습니다. 외부 AI 에이전트가 명령줄이나 CI에서 에디터를 직접 제어할 길은 막혀 있습니다. unityctl은 이 빈틈을 메워, 어떤 LLM이든 자연어로 Unity를 다루도록 잇는 벤더 비종속 오픈소스를 목표로 개발했습니다.
```

**프로젝트 소개** [252/300]
```
unityctl은 외부 AI 에이전트가 Unity 에디터를 제어하도록 돕는 오픈소스 CLI이자 MCP 서버입니다. 씬 조회, 게임오브젝트·컴포넌트 생성/수정, 플레이모드, 스크린샷, C# 스크립트 편집 등 170여 개 명령을 제공합니다. Unity AI가 에디터 UI 안에서만 동작하는 것과 달리, 헤드리스(-batchmode)와 CI에서도 결정적으로 작동합니다. .NET 10 기반에 887개 자동화 테스트와 3개 OS CI로 신뢰성을 확보했습니다.
```

**기대 효과** [399/500]
```
unityctl은 AI 에이전트에게 Unity를 다룰 '손과 눈'을 줍니다. 반복적인 씬 구성·컴포넌트 설정·빌드 검증을 자연어 지시로 자동화하고, 스크린샷으로 결과를 직접 확인하는 폐루프를 제공해 단순 코드 생성을 넘어 실제 동작하는 게임을 만드는 자율 개발로 나아갑니다. Unity API를 깊이 몰라도 자연어로 프로토타입을 만들 수 있어 1인 개발자와 교육 현장의 진입 장벽을 낮춥니다. 나아가 AI와 게임엔진 연동 분야에 표준 MCP 인터페이스와 887개 테스트·CI를 공개해, .NET·Unity 커뮤니티가 함께 키워갈 토대를 마련합니다.
```
